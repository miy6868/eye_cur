# 눈·입 판정

지금 문턱값은 `config.toml` `[mouth]`·`[eyes]`를 본다. 아래는 바꾼 이유.

## 입
- MAR = 입술 안쪽 위아래 거리 ÷ 입 너비. 벌림·다뭄 문턱값을 따로 두어 경계에서 상태가 깜빡이지 않게 한다.
- 처음 벌림 0.30 / 다뭄 0.20은 입을 꽤 크게 벌려야 해서 낮췄다.
- 말할 때 짧게 벌어지는 입은 클릭 최소 시간으로 거른다.

## 눈
- 사람마다 눈 크기가 달라서, 개인별 평소 뜬 눈(최근 값의 80분위) 대비 비율로 판정한다. 두 눈이 모두 넘어야 한다.
- '감는 중'이면 시선 값을 쓰지 않는다. 감는 중이나 얼굴을 놓친 직후 잠시 동안은 시선 결과를 버린다.
- 처음 감는 중 0.78 / 감음 0.70 / 다시 뜸 0.80이었다. 아래쪽을 볼 때 눈꺼풀이 내려와 평소에도 0.66~0.8까지 떨어져서, 눈을 뜨고 있는데 시선이 자주 멈췄다. 그래서 낮췄다.

## 클릭 판정
- 클릭은 입을 다무는(눈 클릭이면 뜨는) 순간 한 번. 최대 시간을 넘기면 클릭 대신 메뉴(`result === 'long'`).
- 진행 고리는 처음부터 앞으로 지날 구간 색(회색 → 초록 → 보라)을 옅게 보여 주고 지난 만큼 진하게 칠한다. 사용자가 시간을 세지 않고 원하는 색에서 다물게 하려는 것.
