## 설치

### Windows
1. 프로젝트 폴더를 `C:\eye_cur`처럼 **영어로만 된 경로**에 둡니다. 경로에 한글이 있으면(한글 폴더 이름, 한글 사용자 이름, OneDrive의 `바탕 화면` 등) 시선 인식이 되지 않습니다. 폴더를 옮겼다면 설치를 다시 해야 합니다.
2. [uv](https://docs.astral.sh/uv/getting-started/installation/)를 설치합니다.
3. 프로젝트 폴더를 열고, 파일 탐색기 주소창에 `powershell`을 입력한 뒤 Enter를 누릅니다.
4. 열린 창에 아래 명령을 붙여 넣고 Enter를 누릅니다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1
   ```
   마지막에 `PASS`가 나오면 설치가 끝난 것입니다.

### Linux
```bash
sudo pacman -S uv      # Arch 기준
./setup.sh
.venv/bin/python scripts/check_camera.py   # 선택: 카메라와 시선 인식이 되는지 확인
```

### Chrome 확장 프로그램
1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 프로젝트 안의 `extension` 폴더를 고릅니다.
4. 확장 프로그램 세부정보에서 사이트 액세스를 **모든 사이트에서**로 바꿉니다.

## 실행과 보정
1. 서버를 켭니다.
   - Windows: `powershell -ExecutionPolicy Bypass -File .\start.ps1`
   - Linux: `./start.sh`

   카메라가 여러 대면 몇 번 카메라를 쓸지 묻습니다. 그냥 Enter를 누르면 `config.toml`에 적힌 카메라를 씁니다.
2. 창에 나온 **연결 토큰**을 복사합니다. Windows 10에서는 글자를 드래그해 둔 채로 두면 서버가 멈추니, 복사한 다음 `Esc`를 반드시 누르세요.
3. 쓰고 싶은 웹페이지를 엽니다. 처음이라면 시험용 페이지 `http://127.0.0.1:8765/demo`를 추천합니다.
4. Chrome 오른쪽 위의 확장 프로그램 아이콘을 누르고, 토큰을 붙여 넣은 뒤 **시작**을 누릅니다.
5. 보정을 합니다. 머리를 움직이지 말고 화면에 나오는 초록 점을 차례로 바라보세요.
   - 첫 점은 나타났다가 한 번 작아지고, 잠시 뒤 **한 번 더 작아질 때** 보정이 시작됩니다.
   - 다음 점이 나올 자리는 회색 점선 원으로 미리 보여 줍니다.
   - 끝나면 오차가 표시됩니다. 오차가 크면 **그래도 사용**과 **다시 보정** 중에서 고를 수 있습니다.
6. 다 쓰면 확장 프로그램 아이콘을 누르고 **중지**를 누릅니다.

보정 결과는 저장되기 때문에 탭을 옮기거나 Chrome을 껐다 켜도 다시 할 필요가 없습니다. 단, 창 크기나 위치를 바꾸면 다시 보정해야 합니다. 사이트마다 페이지 확대 비율이 달라도(Ctrl + 휠) 보정은 그대로 씁니다.

Chrome 설정 화면이나 새 탭 화면, 다른 프로그램을 보고 있을 때는 잠시 멈춥니다. 일반 웹페이지로 돌아오면 다시 동작합니다.

저조도 환경에서는 카메라의 성능에 따라 정확도가 크게 바뀌며, 안경 착용시 빛반사를 고려해야합니다.

## 클릭하기
1. 누르고 싶은 버튼이나 링크를 바라봅니다. 잠깐 보고 있으면 **초록색 테두리**가 생깁니다.
2. 입을 벌립니다. 테두리가 주황색으로 바뀌고, 커서 주위에 원이 조금씩 채워집니다.
3. 원하는 색까지 채워졌을 때 입을 다뭅니다.

| 원의 색 | 입을 다물면 |
|---|---|
| 회색 `…` | 아무 일도 일어나지 않습니다 |
| 초록 `클릭` | 클릭됩니다. 고른 대상이 없으면 빨간색 `대상 없음`이 나옵니다 |
| 보라 `메뉴` | 메뉴가 열립니다. 메뉴가 이미 열려 있으면 닫힙니다 |

입 대신 두 눈을 감았다 떠서 클릭하고 싶다면 `config.toml`에서 `[click]`의 `mode`를 `"eyes"`로 바꾸세요.

입을 벌리고 있는 동안 화면이 스크롤되거나, 탭이 바뀌거나, 카메라가 얼굴을 놓치면 클릭은 취소됩니다.

## 메뉴
메뉴 버튼도 똑같이 바라본 뒤 입을 벌렸다 다물어서 누릅니다. 닫을 때는 왼쪽 아래의 빨간 **닫기**를 누르세요.

| 버튼 | 기능 |
|---|---|
| 뒤로 / 앞으로 / 새로고침 | 브라우저의 버튼과 같습니다 |
| 스크롤 | 화면 위쪽을 보면 위로, 아래쪽을 보면 아래로 내려갑니다. 화면 끝에 가까울수록 빨라지고, 가운데를 보면 멈춥니다. 입을 벌렸다 다물면 스크롤 모드가 끝납니다 |
| 탭 | 지금 창에 열린 탭들이 큰 카드로 나옵니다. 하나를 고르면 그 탭으로 이동합니다 |
| 키보드 | 화면 키보드를 엽니다 |
| 바로가기 | `config.toml`의 `[shortcuts]`에 적어 둔 사이트로 바로 갑니다. 적어 둔 사이트가 없으면 이 버튼은 나오지 않습니다 |

## 가상 키보드
- 한글 두벌식과 영어 자판을 쓸 수 있습니다. 한/영 전환, Shift, 숫자·기호(123), 스페이스, 지우기, 엔터, 모두 지우기 키가 있습니다.
- 맨 위 줄에는 입력칸에 쓴 내용이, 그 아래 줄에는 **추천 단어**가 나옵니다. 추천 단어를 누르면 단어와 띄어쓰기가 한 번에 들어갑니다.
- 웹페이지의 입력칸을 시선으로 누르면 키보드가 자동으로 열립니다. 이 기능은 팝업 창에서 끌 수 있습니다.
- 키보드가 열려 있어도 웹페이지의 입력칸이나 검색어 자동완성 목록을 누를 수 있습니다.

**내가 자주 쓰는 단어 추가하기**
1. 프로젝트 폴더의 `my_words.txt`를 엽니다.
2. 이름, 학교, 자주 쓰는 말 등을 한 줄에 하나씩 적습니다. `#` 뒤에 쓴 내용은 메모로 보고 무시합니다.
3. 메모장이라면 저장할 때 인코딩을 **UTF-8**로 고릅니다.
4. 팝업 창에서 **중지**를 누른 뒤 다시 **시작**을 누르면 적용됩니다.

한글이 들어간 단어는 한글 자판에서, 나머지는 영어 자판에서 추천됩니다.

## 팝업 창
확장 프로그램 아이콘을 누르면 나오는 창입니다.
- **다시 보정**, **중지** 버튼과 현재 상태, 마지막 보정 오차가 보입니다.
- **화면에 정보 표시**: 켜면 왼쪽 아래에 눈·입 인식 상태와 그래프가 나옵니다. 이때 `F` 키로 커서 떨림 보정 방식을 바꿀 수 있고, `ESC` 키로 중지할 수 있습니다. 끄면 커서와 테두리만 보입니다.
- **입력칸을 누르면 키보드 표시**: 끄면 키보드는 메뉴에서만 열 수 있습니다.

## 설정 바꾸기
설정은 모두 [`config.toml`](../config.toml) 파일에 있습니다. 파일을 고친 뒤에는 **서버를 껐다 다시 켜고, 보고 있던 웹페이지도 새로고침**해야 적용됩니다.

자주 바꾸는 항목은 다음과 같습니다.
- `camera_index`: 사용할 카메라 번호
- `[click]`: 입으로 클릭할지 눈으로 클릭할지, 몇 초 동안 벌려야 클릭이나 메뉴가 되는지
- `[mouth]`: 입을 얼마나 벌려야 벌린 것으로 볼지
- `[shortcuts]`: 바로가기에 넣을 사이트
- `save_calibration_log`: 보정 기록을 `logs` 폴더에 남길지 정합니다. 카메라 영상은 저장하지 않습니다

## 문제 해결
| 문제 | 해결 방법 |
|---|---|
| 설치할 때 `DLL load failed`가 나옵니다 | [Visual C++ 재배포 패키지](https://aka.ms/vs/17/release/vc_redist.x64.exe)를 설치하세요. Windows N·KN 버전이라면 미디어 기능 팩도 설치해야 합니다 |
| 시선 인식 모델이 열리지 않습니다 | 폴더 경로에 한글이 있는지 확인하세요 |
| 카메라가 켜지지 않습니다 | 다른 프로그램(줌, 카메라 앱 등)이 카메라를 쓰고 있지 않은지, `camera_index` 번호가 맞는지 확인하세요. Linux라면 사용자가 `video` 그룹에 들어 있어야 합니다 |
| 확장 프로그램을 새로고침했는데 바뀐 게 없습니다 | 보고 있던 **웹페이지도 새로고침**하세요 |
| 커서가 보는 곳과 많이 다릅니다 | 팝업 창에서 **다시 보정**을 누르세요. 밝은 곳에서, 머리를 움직이지 않고 하는 게 좋습니다. 안경 착용시 렌즈의 두께나 빛 반사 등이 영향을 줄 수 있습니다 |
| 보정이 끝나고 "보정 자료가 부족합니다."가 나옵니다 | 서버를 종료한 뒤 카메라 앱에서 얼굴이 모두 카메라에 나오고 있는지 확인하세요 |
| 클릭이 비정상적으로 됩니다 | 서버를 종료한 뒤 카메라 앱에서 얼굴이 모두 카메라에 나오고 있는지 확인하세요. 얼굴이 모두 나오고 있는 상태였다면 config.toml에서 조정해보세요 |


## 지원하지 않는 것
- 드래그, 파일 선택 창, 브라우저 자체의 메뉴
- 일부 특수한 버튼(웹 게임처럼 화면 전체가 그림으로 그려진 곳의 버튼, 페이지 안에 겹겹이 들어간 영역 속 버튼 등)
- 다른 사이트를 끼워 넣은 영역의 스크롤(예: 네이버 지도 검색 목록). 네이버 블로그 본문처럼 같은 사이트 영역은 스크롤됩니다
- 페이지 안에 끼워 넣은 영역의 입력칸에 가상 키보드로 입력하기
- 탭 닫기(잘못 누르면 되돌리기 어려워 일부러 넣지 않았습니다)

정확도는 사람과 카메라에 따라 달라 직접 보정해 봐야 알 수 있습니다.

서버는 이 컴퓨터 안에서만 연결을 받고, 연결 토큰이 맞는지 확인합니다. 카메라 영상이나 시선 정보는 인터넷으로 보내지 않습니다.
