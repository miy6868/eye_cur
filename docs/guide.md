## 설치

### Windows
1. 프로젝트 폴더를 `C:\eye_cur`처럼 **영어로만 된 경로**에 둡니다. 한글 폴더, 한글 사용자 이름, OneDrive `바탕 화면` 아래에서는 시선 인식이 동작하지 않습니다. 폴더를 옮겼다면 setup을 다시 실행합니다.
2. [uv](https://docs.astral.sh/uv/getting-started/installation/)를 설치합니다.
3. 그 폴더에서 일반 PowerShell 창을 엽니다(ISE나 우클릭 실행은 안 됩니다).
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1
   ```
   마지막 점검에서 `PASS`가 나오면 끝입니다.

### Linux
```bash
sudo pacman -S uv      # Arch 기준
./setup.sh
.venv/bin/python scripts/check_camera.py   # 선택: 카메라·얼굴·시선 확인
```

### Chrome 확장
`chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더를 고릅니다. 사이트 액세스는 **모든 사이트에서**로 둡니다.

## 실행과 보정
1. 서버를 켭니다. Windows `powershell -ExecutionPolicy Bypass -File .\start.ps1`, Linux `./start.sh`.
   - 카메라가 여러 대면 번호를 묻습니다. Enter를 누르면 `config.toml`의 번호를 씁니다.
   - 콘솔에 나온 **연결 토큰**을 복사합니다. Windows 10 콘솔은 글자를 선택한 채로 두면 서버가 멈추므로, 복사한 뒤 `Esc`를 누릅니다.
2. 아무 웹페이지를 엽니다. 시험해 볼 때는 `http://127.0.0.1:8765/demo`가 좋습니다.
3. 확장 아이콘 → 토큰 입력 → **시작**.
4. 보정: 머리를 고정하고 화면에 나오는 초록 점을 바라봅니다.
   - 첫 점이 크게 나타났다 작아지고, **한 번 더 작아지면** 진짜 시작입니다.
   - 다음 점 자리는 회색 점선 원으로 미리 보입니다. 점이 작아지는 동안 눈을 옮기면 됩니다.
   - 끝나면 "점 오차"가 나옵니다. 크면 **그래도 사용** 또는 **다시 보정**을 고릅니다.
5. 끝낼 때는 확장 아이콘 → **중지**.

보정은 저장되어 탭을 바꾸거나 브라우저를 다시 켜도 이어집니다. 창 크기·위치·화면 배율이 바뀌면 다시 보정합니다.
Chrome 설정·새 탭처럼 확장이 들어갈 수 없는 페이지나 다른 앱에 있을 때는 멈췄다가, 일반 웹페이지로 돌아오면 다시 이어집니다.

## 클릭
1. 버튼·링크를 바라봅니다. 잠시 보고 있으면 **초록 테두리**가 생깁니다.
2. 입을 벌리면 테두리가 주황색이 되고, 커서 자리에 고리가 차오릅니다.
3. 고리 끝의 색과 아래 글자가 "지금 다물면 일어나는 일"입니다.

| 고리 색 | 다물면 |
|---|---|
| 회색 `…` | 아무 일 없음(너무 짧음) |
| 초록 `클릭` | 클릭 (대상이 없으면 빨강 `대상 없음`) |
| 보라 `메뉴` | 메뉴 열기 (메뉴가 떠 있으면 `메뉴 닫기`) |

`config.toml`에서 `[click] mode = "eyes"`로 바꾸면 입 대신 **양눈을 감았다 떠서** 클릭합니다.
스크롤, 탭 전환, 얼굴을 놓치면 진행 중인 클릭은 취소됩니다.

## 메뉴
메뉴 버튼도 똑같이 바라보고 입으로 누릅니다. 맨 아래 왼쪽 붉은 **닫기**로 닫습니다.

| 버튼 | 하는 일 |
|---|---|
| 뒤로 / 앞으로 / 새로고침 | 브라우저와 같음 |
| 스크롤 | 화면 위·아래 띠를 보면 그쪽으로 스크롤. 끝에 가까울수록 빠르고, 가운데를 보면 멈춤. 입을 벌렸다 다물면 끝 |
| 탭 | 이 창의 탭이 큰 카드로 나오고, 고르면 그 탭으로 감 |
| 키보드 | 가상 키보드 열기 |
| 바로가기 | `config.toml` `[shortcuts]`에 적은 사이트로 이동(비어 있으면 버튼 없음) |

## 가상 키보드
- 두벌식 / QWERTY. 한/영, Shift, 123(숫자·기호), 스페이스, 지우기, 엔터, 모두 삭제가 있습니다.
- 맨 위 줄에 입력칸 내용이 보이고, 그 아래에 **추천 단어**가 나옵니다. 고르면 단어와 띄어쓰기가 들어갑니다.
- 입력칸을 시선으로 누르면 키보드가 저절로 뜹니다(팝업에서 끌 수 있음).
- 키보드 밖의 페이지 요소(입력칸, 자동완성 목록)도 그대로 누를 수 있습니다.

**내 단어 추가**: 저장소 맨 위 `my_words.txt`에 한 줄에 하나씩 적습니다(이름, 학교, 자주 쓰는 말 등). 한글이 있으면 한글 키보드, 아니면 영어 키보드에서 추천됩니다. `#` 뒤는 무시합니다. 메모장에서는 **UTF-8**로 저장하고, 팝업에서 중지 → 시작하면 적용됩니다.

## 팝업
- **다시 보정**, **중지**, 상태와 마지막 보정의 점 오차
- **화면에 정보 표시**: 켜면 왼쪽 아래에 눈·입 상태와 그래프가 보이고, 단축키 `F`(떨림 필터 바꾸기)·`ESC`(중지)가 동작합니다. 끄면 커서와 테두리만 보입니다.
- **입력칸을 누르면 키보드 표시**: 끄면 키보드는 메뉴로만 엽니다.

## 설정
모든 설정은 [`config.toml`](../config.toml)에 있고, 값마다 설명이 달려 있습니다. 고친 뒤에는 **서버를 다시 켜고 쓰던 웹페이지도 새로고침**합니다.

자주 바꾸는 것:
- `camera_index`: 카메라 번호
- `[click]`: 클릭 방식(입/눈), 클릭·메뉴로 인정하는 시간
- `[mouth]`: 입을 얼마나 벌려야 인식할지
- `[shortcuts]`: 바로가기 사이트
- `save_calibration_log`: 보정 기록을 `logs/`에 남길지(카메라 영상은 저장하지 않음)

## 문제 해결
| 증상 | 해결 |
|---|---|
| setup에서 `DLL load failed` | [VC++ 재배포 패키지](https://aka.ms/vs/17/release/vc_redist.x64.exe) 설치. Windows N/KN 에디션은 미디어 기능 팩도 필요 |
| 시선 모델이 안 열림 | 폴더 경로에 한글이 없는지 확인 |
| 카메라가 안 열림 | 다른 프로그램이 카메라를 쓰는지, `camera_index`, Linux는 `video` 그룹 권한 확인 |
| 확장을 새로고침했는데 그대로임 | 쓰던 **웹페이지도 새로고침** |
| 커서가 많이 빗나감 | 팝업 → **다시 보정**. 밝은 곳에서, 머리를 고정하고 |

## 안 되는 것
- iframe 속 iframe, Shadow DOM 안쪽, canvas 속 버튼, 파일 선택기, 브라우저 메뉴, 드래그
- 다른 사이트 iframe 안의 스크롤(네이버 지도 목록 등). 같은 사이트 iframe(네이버 블로그 본문)은 됩니다
- iframe 안 입력칸에 가상 키보드로 입력
- 탭 닫기(실수하면 되돌리기 어려워 넣지 않음)
- 정확도는 사람과 카메라마다 달라서 직접 보정해 봐야 압니다

로컬 서버는 이 컴퓨터(`127.0.0.1`)에서만 받고, 연결 토큰을 검사합니다. 외부로는 아무것도 보내지 않습니다.
